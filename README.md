# Cyclistic-Bikeshare-Analysis-Project

Purpose of this project is to find trends that could help in converting casual riders to members. 

Vizualizations for this project can be found at this link: https://public.tableau.com/views/2025CyclisticBikeshare/Story1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link
## Data Source

This project uses the Divvy/Cyclistic historical trip dataset made available by Lyft Bikes and Scooters, LLC and the City of Chicago.

Dataset source:
https://divvybikes.com/system-data
